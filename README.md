## Billetera Digital

Aplicación web desarrollada como parte del T1 del curso Soluciones Web y Aplicaciones Distribuidas. El proyecto implementa una billetera digital utilizando Java, Servlets, JSP, Jakarta y Bootstrap

## Descripción
La aplicación permite administrar una billetera digital mediante:

    - Visualización del saldo actual.
    - Registro de recargas.
    - Registro de gastos.
    - Validación de montos.
    - Validación para evitar gastos mayores al saldo disponible.
    - Visualización del historial de movimientos.
    - Ordenamiento de movimientos desde el más reciente al más antiguo.
    - Formateo de valores monetarios (debido a la configuración regional se está considerando coma decimal y punto de millares).
    - Manejo de errores mediante mensajes en la interfaz.

La información se mantiene en memoria durante la ejecución de la aplicación.

## Tecnologías utilizadas
    - Java 21
    - Jakarta Servlet 6.0
    - JSP
    - Jakarta Tags / JSTL
    - Apache Tomcat 10.1.10
    - Maven
    - Bootstrap 5
    - Visual Studio Code
